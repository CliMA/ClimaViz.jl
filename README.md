# ClimaViz.jl - Climate Model Visualization Framework

A visualization framework for climate models.

## ParamViz.jl

ParamViz.jl is available as a sub-package in the `ParamViz.jl/` directory. It provides dynamic parameterization web app capabilities.

### Using ParamViz

For detailed ParamViz documentation and examples, see [ParamViz.jl/README.md](ParamViz.jl/README.md).

## Installation

ClimaViz.jl will be registered in the Julia General registry. Once registered, you can install it using:

```jl
julia> ]
pkg> add ClimaViz
```

For development installation:
```jl
julia> ]
pkg> add https://github.com/CliMA/ClimaViz.jl
```
